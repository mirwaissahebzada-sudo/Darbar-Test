مدیریت کارگاه لیزری دربار

این برنامه یک سامانه محلی برای ثبت مشتری، سفارش، دریافت و پرداخت، مصارف، کارمندان و موجودی انبار است.

نصب در GitHub Pages:
۱) پیش از جایگزینی، از داده‌های برنامه در تنظیمات پشتیبان JSON بگیرید.
۲) فایل‌های این پوشه را مستقیماً در ریشه شاخه main مخزن بارگذاری کنید.
۳) پس از انتشار، سایت را دوباره باز کنید. اگر نسخه قدیمی ماند، کش سایت را پاک کرده یا در Safari صفحه را دوباره بارگذاری کنید.
۴) برای انتقال اطلاعات، از تنظیمات > بازیابی پشتیبان، فایل JSON را انتخاب کنید. پشتیبان قدیمی با ساختار customers/orders/receipts/expenses/items/moves نیز به‌صورت تبدیل‌شده پذیرفته می‌شود.

توجه: برنامه به‌صورت پیش‌فرض اطلاعات را فقط در همان مرورگر و دستگاه ذخیره می‌کند. پشتیبان‌گیری منظم ضروری است.

برای جزئیات تغییرات و محدودیت‌ها، فایل CHANGELOG-FA.txt را بخوانید.
